## v45：显式逐大步认证

在每个内步的第一个外子步，用纯整数位模式检查整个 COR 场，允许
有限正规数精确乘 0.25 和有符号零；其余数据/不支持的 ABI/显式关闭
均回退。对已认证的正压 CLAMPED 持久团队，后续子步曲率初始化与
BCOND(12) 并行，保留曲率循环末屏障，保证 ELF mask 前发布边界结果。
后面的 TY 扫描发布平流结果的屏障亦不可删除。

科学检查通过，速度筛查未通过：同批 v44 两次 10.793934、10.875518 秒；
v45 12.393179、12.442905 秒，0/2 快，中位反慢 14.61%。没有跑确认或
单核计时，不晋升。扫描合计约 3.42 GB 原始 COR 数据，还有约 8.55 亿
次元素位检查；净成本必须用测量决定，不能只数减少的屏障。

本地 24 配置×2 子步×20 域、1/3 线程逐位回归与去屏障负控见
`v45/safety-result.json`。Linux 原生 sNaN 顺序验证见
`v45/linux-order.log`；Mac 上旗标不构成实际 SIGFPE 证明，二者明确分列。

## v46：利用首个子步既有计算

仅同一持久线程组、正压 CLAMPED 的 IEXT>1 前移曲率初始化；IEXT=1
保持原始 DO95。冻结科学树证明外子循环不改 COR，不改浮点环境/陷阱
设置、不读清异常标志、没有异常处理后继续的路径，且两循环用相同
无 chunk STATIC 行分配。首个子步若失败，仍在原位置失败；后续相同
线程对相同数据重做相同乘法，不需要再加全场认证扫描。
该依据不能外推到未来可修改 COR 或浮点环境的其他调用者。

源和补丁分别由 `v45/prepare.py`、`v46/prepare.py` 生成，不修改输入、
输出采样、物理或计算精度。两个环境开关分别为 SECOM_V45_OVERLAP 和
SECOM_V46_OVERLAP；值 0 强制回退。最终性能取舍以 validation/OMP64.md
当日更新为准，代码存在不代表已接受。

## 重现源生成与隔离检查

从仓库根目录执行（目标必须是新目录）：

```sh
python3 -B campaign/overlap-trials/v45/prepare.py --repo . --out /tmp/secom-v45-new
python3 -B campaign/overlap-trials/v46/prepare.py --repo . --out /tmp/secom-v46-new
python3 -B campaign/overlap-trials/v45/tests/verify.py --repo . --probe campaign/overlap-trials/probe-v34.f --fc gfortran
```

测试夹具不是完整海洋求解器；原生完整开发算例另有早5/晚7帧×25域、
显式关闭及旧主控回退、六输出原始字节、实际TID/物理核绑定及外部负载审计。
所有计时从进程启动到退出，包含输出和新增保护成本；忙核预检确认未启动
才可等待重试，失败/慢样本不删除。无需 root 权限，不使用共享性能样本。
